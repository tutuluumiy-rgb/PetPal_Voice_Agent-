# 前端接入指引 · 语音能力规划与分工记录

> 本文档记录「Electron 前端接入真实后端/语音」的架构决策、当前进度、环境限制与职责划分。
> 目的：让移除测试看板（testboard）后 Electron 前端仍能独立具备语音能力；明确后端（本仓库）与前端（UI/交互）的分工。

## 1. 当前环境限制（重要）

- **本开发环境（沙箱）无法访问 npm registry**：`npm install` 实际未成功（`node_modules` 为空），
  **无法安装前端依赖、无法构建 Electron、无法启动 Electron GUI 做运行测试**。
- 因此：**「真实接入前端并试效果」必须在你的机器上完成**（你机器可访问 npm registry、可跑 GUI）。
- 从上代看板（testboard）继承的验证方式：后端用 `python main.py` 跑在 8001；
  前端桌面上 `cd frontend && npm install && npm run dev` 启动 Electron。

## 2. 已完成：VAD 资产迁移（不依赖 testboard）

测试看板的 VAD 资源已整体复制到 Electron 前端，**前端不再依赖 testboard/vad**：

```
frontend/renderer/assets/vad/
  ort.min.js                onnxruntime-web（UMD）
  bundle.min.js             @ricky0123/vad-web（UMD，MicVAD）
  silero_vad.onnx           Silero VAD 模型
  ort-wasm*.wasm / *.worker.js   onnxruntime WASM
  vad.worklet.bundle.min.js Silero VAD worklet
```

> 说明：VAD 依赖 Web Audio 生态（`getUserMedia`/`AudioContext`），**必须在 Electron 的 renderer
> （浏览器环境）运行**，不能用主进程 Node 环境。测试看板正是用 `<script src="./vad/...">` 加载这套 UMD 库。

## 3. 职责划分（按你的第 3 点）

| 职责 | 归属 | 说明 |
|---|---|---|
| UI / 交互 / 窗口 / 设置页 | **前端（UI Agent）** | 只改 `frontend/renderer` 视图、IPC、样式 |
| 后端业务：LLM / ASR / TTS / 工具 / 状态机 / 历史 | **后端（本仓库）** | `backend/*` |
| 语音采集 + VAD 打断 | **后端职责（由本仓库给出方案/样板）** | 复刻测试看板的采集+VAD 逻辑 |
| **KWS 唤醒词** | **本仓库（后续实现）** | Electron 阶段用轻量 KWS 模型 CPU 常驻（方案见 `docs/placeholder_and_kws.md`） |
| 主进程 WebSocket 客户端（连后端） | **本仓库（提供样板）** | 按 `docs/MOCK_CONTRACT.md` / 交底协议连 Mock 或真实后端 |
| 占位音频（等待/失败/连接提示） | **本仓库生产 + 前端播放** | 资源在 `frontend/`（Electron）或 `testboard/audio/`（看板） |

## 4. Electron 语音接入建议架构（已确认：renderer 直连音频 WS）

```
renderer（浏览器环境）
  getUserMedia 采集 PCM ──► 前端 Silero VAD（MicVAD，wasm）──► 打断/端点
        │                                                       │
        └──────────► 语音 WebSocket（直连，见下方决策）─────────┘
        │
        └──(少量控制事件 IPC)──► 主进程 → 后端（控制/设置/历史等）
```

- **VAD 放 renderer**（依赖 Web Audio 生态：`getUserMedia`/`AudioContext`）。
- **【已确认】renderer 可直连音频/语音 WebSocket**（与测试看板一致，性能好、复刻简单）；
  UI/条件/设置等控制走主进程（业务逻辑不依赖 renderer 碰控制网络的限制依然成立）。
- VAD 资源已复制到 `frontend/renderer/assets/vad/`，renderer 直接引用（不依赖 testboard/vad）。

> ⚠️ renderer 的 `pet.html`/`panel.html` 有 CSP `script-src 'self'`：VAD 的 UMD 脚本与 wasm/onnx
> 需作为同源静态资源打包进产物（electron-vite 处理），并可能需要为 Web Audio/Media 放宽 CSP
> （`media-src`/`worker-src` 等）。此项需在本机构建 Electron 时验证。

## 5. 本机验证步骤（在你机器上执行）

```powershell
# ① 后端真实服务（8001）
cd backend && python main.py

# ② Mock 服务器（若只开发 UI，9000，不连真实库）
cd backend && python mock_server.py

# ③ 前端 Electron（首次需装依赖）
cd frontend && npm install && npm run dev
```

验证链条：`auth` 握手 → `mode:get`/`chat:send` 文本 → `tts:start/end` 动画 → `history` → 设置页 → KWS（后续）。
