# 前端开发任务提示词（给前端 Agent / 前端工程师）

> 直接复制下面「任务提示词」整段给你的前端开发（人或 Agent）即可。
> 下面是你在接手前必须先知道的工程边界与当前状态，务必通读。

---

## 一、硬性边界（不可逾越）

1. **只允许改动 `frontend/` 目录**（`frontend/main`、`frontend/preload`、`frontend/renderer`、`frontend/docs`、`frontend/scripts`、`frontend/package.json` 等）。
2. **绝对禁止改动后端**：`backend/`、`testboard/`、根目录 `docs/`。后端代码、前后端协议、接口字段一律不许动。
3. **不允许改协议 / 契约**：前端对接后端的消息字段、事件名、端口（真实 8001 / Mock 9000）是既定的，由后端团队维护。你只实现前端的「消费 / 展示 / 交互」，不新增或改名任何协议字段。
4. **大模型资源 / 模型 / 密钥**：不提交任何 `.onnx`/`.wasm` 模型文件、`.env`、密钥；`frontend/resources/kws`、`frontend/renderer/public/kws`、`frontend/renderer/public/vad/*.onnx|*.wasm` 已被 gitignore，勿手动入库。

---

## 二、当前工程状态（你要在此基础上继续，不要推倒重来）

- **前端**：Electron-Vite + Vue3 + TypeScript。进程分层：`main`（主进程）/ `preload`（IPC 桥接）/ `renderer`（视图）。
- **语音链路（已通）**：`frontend/renderer/app/voice/VoicePipeline.ts` 直连真实后端 **8001** `/ws/audio`：
  - 前端→后端：二进制 PCM（Int16 16k）+ JSON 控制（`speech_start` / `speech_end` / `vad_cancel`）
  - 后端→前端：JSON（`ready` / `asr_partial` / `asr_final` / `reply_start` / `reply` / `reply_append` / `reply_end` / `tts_start` / `tts_end` / `barge_confirm` / `barge_reject` / `stop_playback`）+ 二进制 TTS PCM（24k）
  - 已含：待机听唤醒（主进程 `sherpa-onnx-node` KeywordSpotter，IPC `kws:feed` / `kws:wake`）→ 命中进对话 → 说完回待机。
  - 已在 `ChatPanel.vue`（独立对话面板窗口，承载语音管线）接入并**验证通过**。
- **协议文档（你只管读 / 消费，不可改）**：
  - 真实语音协议：`backend/MESSAGE_CONTRACT.md`（8001 `/ws/audio`）
  - Mock 协议（UI 联调用，9000 方案 A）：`backend/docs/MOCK_CONTRACT.md`
  - 分工 / 待办：`backend/docs/前端接入指引.md`

---

## 三、当前待办（前端职责，可按此优先级排）

> 这些是**前端未完成**的部分，全部在 `frontend/` 内实现。后端对应能力可能还是 Mock（9000），
> 你对接时**用 Mock 验证 UI/交互**即可，真实后端是否实现由后端团队决定，**你不负责也不催后端**。

### P0 打通控制面板 → 后端（Mock 9000 方案 A）
目前控制面板各设置页是 TODO 占位，需要按 `backend/docs/MOCK_CONTRACT.md` 的协议接上：
1. **文本对话**：`ChatInputBar.vue` 的 `send()` 接 `chat:send`（流式 `start/delta/done`），并把回复追加到 `ChatPanel` 消息区；`abort`/`isRunning` 接 `chat:running` / `chat:abort`。
2. **历史记录**：`HistoryView.vue` 接 `history:list` / `history:search`（分页）。
3. **人设 / 用户档案**：`PersonalityView.vue` / `UserProfileView.vue` 接 `personality:get/set`、`user:get/set`（markdown 编辑）。
4. **语音参数**：`VoiceSettingsView.vue` 接 `voice:settings:get/set`（vol/pitch/voice 滑块）。
5. **模式 / 权限**：确认 `mode:get/set`、`auth:policy:get/set` 当前 UI 与 Mock 联动一致（单选卡片 + 广播同步）。

> 连接方式：Mock 在 `ws://127.0.0.1:9000/ws`，走**主进程**网关（`main/` 新增 service 层连 WS，再经 IPC 暴露给 renderer，渲染进程不直接碰网络——除语音音频 WS 之外）。

### P1 语音体验完善（后端职责之外的 UI/交互）
- 语音按钮态 / 待机提示 / 唤醒反馈文案与状态停留优化。
- 打断、关闭面板等与语音状态的联动 UI。

### P2 收尾清理
- **testboard 移除自检**：确认前端运行**不依赖 `testboard/` 任何文件/路径**（VAD 已迁到 `frontend/renderer/public/vad/`，KWS 在主进程）。
- 设置页空态/加载/错误态处理。
